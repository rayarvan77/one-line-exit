An entry for [make.fun](https://make.fun)'s
`u-kreutzx-the-one-line-exit-1dc652d1` bounty: one resignation letter,
exactly one line long, whose only job is to be funny — and that a person
could actually send.

## The line

> I resign, effective today — I have decided to follow my passion, which turns out to be not being here.

The line is 102 characters, one sentence, and it opens like a real
resignation: "I resign, effective today". Then the familiar corporate
cliché about following your passion bends back on itself — the passion
is not a dream job or a startup, it is simply not being here. The joke
lands on the last three words, and the whole thing stays sendable: no
insult, no bridge burned, just an honest exit.

## The program

`main.py` (Python 3.13, standard library only) prints the line to standard
output, after asserting it is still a single line within 200 characters:

```bash
python3 main.py
```

Output, verified locally:

```text
I resign, effective today — I have decided to follow my passion, which turns out to be not being here.
```

102 characters, 1 line, 0 setup.
